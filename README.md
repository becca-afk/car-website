# Car Retail Website

Multi-page responsive car dealership showcase built with semantic HTML5 and custom CSS3 stylesheets.

## Pages Included
- `index.html` — Dealership landing page
- `inventory.html` — Vehicle catalog & listings
- `product-1.html` – `product-5.html` — Individual vehicle detail pages
- `about.html` & `contact.html` — Dealership background and contact form
- `login.html` — Customer portal layout
